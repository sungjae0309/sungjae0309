## Blockchain / Web3

### [cantor8](https://github.com/sungjae0309/cantor8) · Python
RWA를 담보로 수용한 PoS 체인에서 **단기 검열 공격이 경제적으로 성립하는지** 정량 분석하는 시뮬레이션입니다.
공격 비용(CoC)과 공격 수익(PfC)을 시나리오별로 계산해 손익분기점과 최적 중단 슬롯을 탐색합니다.

- 오라클 가격 괴리를 이용한 과대차입·Exit 시나리오, 청산 트랜잭션 선별 검열 시나리오 구현
- 빌더 점유율 기반 연속 검열 확률을 기하분포로 모델링해 기대비용·기대수익 산출
- 수식·경계조건 회귀 테스트 작성
- *4Pillars 블록체인 리서치 챌린지 2026 · Cantor8 트랙*

### [whyblockchain](https://github.com/sungjae0309/whyblockchain) · TypeScript
"왜 블록체인이어야 하는가"를 처음 접하는 사람이 **스스로 판단하도록 돕는** 웹사이트입니다.
장점만 나열하지 않고 비용과 부적합한 사례를 같은 무게로 다루는 것을 원칙으로 삼았습니다.

### [solidity-foundry](https://github.com/sungjae0309/solidity-foundry) · Solidity
Foundry 기반 스마트 컨트랙트 실습 저장소입니다. Forge 테스트를 함께 작성하며 진행 중입니다.
